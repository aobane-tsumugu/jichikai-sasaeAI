## cloud で続ける時

Claude と Codex の連絡網は GitHub の Issue #1 です。作業の前と区切りごとに読みます。

cloud のセッションにあるのはこのリポジトリです。資格情報のファイルと Codex はありません。設計の要約は docs/DESIGN.md、守ることは CLAUDE.md を見ます。

- cloud 環境 jichikai-sasaeAI では `npx wrangler deploy` と `npx wrangler d1 execute DB --remote` が使えます。鍵はネットワークシークレットで、環境変数の CLOUDFLARE_API_TOKEN は目印の文字列です。読み取りは cloud で確認済み、配備は同じ鍵を手元で確認済みです。
- 役員画面に入る資格情報は環境変数 JICHIKAI_OFFICER_NAME と JICHIKAI_OFFICER_PASSWORD にあります（前の審査員用の区 demoku の試しの役員）。`--creds` に渡す時は `printf '名前: %s
パスワード: %s
' ... > /tmp/creds.txt` のようにリポジトリの外へ書きます。値を表示しないでください。
- 秘密の値を書かない、一斉送信をしない、GitHub を公開にしない、は cloud でも同じです。
- 検査は `npm run typecheck` と `npx vitest run`。cloud の新しいセッションには node_modules が無いので、先に `npm ci` を走らせる。
- HTTP で役員画面に入る時は、フォームの POST に `Origin: https://jichikai.aobane-tsumugu.com` を付ける（付けないと CSRF の検査で 403）。
- cloud には gh が無いので、連絡網の Issue は GitHub の MCP で読み書きする。
