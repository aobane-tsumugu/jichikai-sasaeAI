# 自治会運営AI支援（仮称）

自治会の行事や総会などを、準備から記録、次の担い手への引き継ぎまで、プロジェクトごとに扱う運営支援システムです。自治会の役員が持つ紙、写真、ファイル、短いメモをそのまま受け取り、既にある内容とのつながりや確認が必要な点を示すことを目指しています。

## 誰の、どの場面の、どんな困りごとを、どう変えるか

- **誰のために:** 本業や家庭と並行して運営を担い、短い周期で交代する自治会役員が使います。自治会の活動に関わるか迷っている人や、次の担い手にも情報が届くことを目指します。
- **どの場面で:** まず秋の収穫祭の準備を、去年の資料を探すところから、案内、出欠や手伝いの受付、変更、実施報告、来年に使う記録まで追います。
- **どんな困りごとを:** 資料や経緯が役ごとの手元に分かれ、口頭や電話の決定が残らず、紙と Web の案内や回答を別々に作り、集計し、役員交代で経緯が途切れます。
- **どう変えるか:** 役員が資料を事前に分類したり、個人情報を消したり、保存先を判断したりせず、手元の物を送るところから始められる設計です。AI が読み取り、既存のプロジェクトの内容と照合して、変わった点や問い、下書きを提示します。役員が判断し、直して配った内容を記録に残し、紙と Web の案内を同じ内容から作ることを目指します。

対象は事務の層です。印刷、仕分け、配達、回覧、掲示、集金、買い出し、設営と片付け、当日の運営、人との付き合い、本来の判断はなくなりません。操作を含めた負担の変化は測定していません。

### ローカルで起動する

Node.js と npm を用意した環境で、リポジトリのルートから実行します。

```sh
npm ci
npm run db:migrate:local
npm run dev
```

Wrangler の開発サーバーが表示するローカル URL にアクセスしてください。区のデータと役員アカウント、Anthropic の Workload Identity Federation などの連携設定が無い環境では、デモ全体は動きません。秘密情報は `.dev.vars` などのローカル設定に置き、リポジトリや画面に記録しないでください。ローカルの通し動作はまだ確認できていません。

## Claude の使い方

### 運営支援システムの中

- 写真や PDF の読み取りには Anthropic Messages API を使います。Workers から原本を一回の呼び出しで渡し、決めた形式の読み取りを受け取ります。
- 読み取った内容をプロジェクトの状態につなぐ仕事には Claude Managed Agents を使います。役員が送った入力ごとに処理し、Workers が公開する MCP の五つの手を使います。手は「開いているプロジェクトを引く」「プロジェクトの状態を引く」「読み取りを引く」「差分を書く」「問いを書く」です。
- 読み取りや内容の接続には `claude-sonnet-5-5`、候補からプロジェクトを選ぶ単純な処理には `claude-haiku-5-5` を使います。製品内では Opus を使っていません。
- Anthropic の固定 API キーをアプリやリポジトリに置かず、Workload Identity Federation で短期間のアクセストークンを取得する構成です。
- AI は役員の準備作業を支援します。AI の推定を正式な決定にはせず、配布する内容や運営上の判断は人が決めます。配布後の公開ページ、回答、印刷は AI が止まっても使える設計です。

### 開発の進め方

Claude Code の Opus が PM として設計・割り当て・統合を進め、Claude の Sonnet が土台と AI の中心部分を実装し、Codex が画面、架空データ、各部品の接続を担当しました。役割を分けて進めた事実を記し、各機能が完成・検証済みであるという意味には使っていません。
