# 自治会運営AI支援サービス「SasaeAI」

自治会の行事や総会などを、準備から記録、次の担い手への引き継ぎまで、行事ごとに扱う運営支援システムです。自治会の役員が持つ紙、写真、ファイル、短いメモをそのまま受け取り、既にある内容とのつながりや確認が必要な点を示すことを目指しています。

## 誰の、どの場面の、どんな困りごとを、どう変えるか

- **誰のために:** 本業や家庭と並行して運営を担い、短い周期で交代する自治会役員が使います。自治会の活動に関わるか迷っている人や、次の担い手にも情報が届くことを目指します。
- **どの場面で:** まず秋の収穫祭の準備を、去年の資料を探すところから、案内、出欠や手伝いの受付、変更、実施報告、来年に使う記録まで追います。
- **どんな困りごとを:** 資料や経緯が役ごとの手元に分かれ、口頭や電話の決定が残らず、紙とWebの案内や答えを別々に作り、集計し、役員交代で経緯が途切れます。
- **どう変えるか:** 役員が資料を事前に分類したり、個人情報を消したり、保存先を判断したりせず、手元の資料を送るところから始められる設計です。AIが読み取り、既存の行事の内容と照合して、変わった点や質問、下書きを提示します。役員が判断し、直して配った内容を記録に残し、紙とWebの案内を同じ内容から作ることを目指します。

対象は事務の層です。印刷、仕分け、配達、回覧、掲示、集金、買い出し、設営と片付け、当日の運営、人との付き合い、本来の判断はなくなりません。操作を含めた負担の変化は測定していません。

## Claudeの使い方

### 運営支援システムの中

- 写真やPDFの読み取りにはAnthropic Messages APIを使います。Workersから元の資料を一回の呼び出しで渡し、決めた形式の読み取りを受け取ります。
- 読み取った内容を行事の状態につなぐ仕事にはClaude Managed Agentsを使います。役員が送った入力ごとに処理し、Workersが公開するMCPの五つの手を使います。手は「開いている行事を引く」「行事の状態を引く」「読み取りを引く」「差分を書く」「質問を書く」です。
- 読み取りや内容の接続には `claude-sonnet-5-5`、候補から行事を選ぶ単純な処理には `claude-haiku-5-5` を使います。製品内ではOpusを使っていません。
- Anthropicの固定APIキーをアプリやリポジトリに置かず、Workload Identity Federationで短期間のアクセストークンを取得する構成です。
- AIは役員の準備作業を支援します。AIの推定を正式な決定にはせず、配布する内容や運営上の判断は人が決めます。配ったあとの公開ページ、答え、印刷はAIが止まっても使える設計です。

### 開発の進め方

Claude CodeのOpusがPMとして設計・割り当て・統合を進め、ClaudeのSonnetが土台とAIの中心部分を実装し、Codexが画面、架空データ、各部品の接続を担当しました。役割を分けて進めた事実を記し、各機能が完成・検証済みであるという意味には使っていません。

- ローカルの `npm run dev` での通し動作は確かめていません。
