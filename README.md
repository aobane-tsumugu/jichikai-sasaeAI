# jichikai-sasaeAI

自治会運営AI支援（仮称）。自治会の役員の事務の仕事を、行事や総会といったプロジェクトごとに開く一つの場で通すソフトウェアです。Built with Claude Japan 2026 の提出作品で、大会期間中（2026-11-02 13:03 JST 以降）に新しく作っています。

いま作っている途中です。動いている範囲は [docs/STATE.md](docs/STATE.md) にあり、確かめた物だけを済みと書きます。

## 誰の、どの場面の、どんな困りごとを、どう変えるか

- 誰の: 自治会の役員です。本業と家庭があり、一年ほどで交代します。届けたい相手は、未加入の人と次の担い手です。
- どの場面の: 秋の収穫祭の準備です。去年の資料を探す所から、案内を配り、出欠と手伝いを集め、雨で会場が変わり、報告を書いて来年へ渡す所までです。
- どんな困りごとを: 去年の資料が役ごとの手元に散っています。決まったことは口頭と電話で、どこにも残りません。紙と Web を別々に作り、紙と電話と Web の答えを手で寄せて数えます。交代すると経緯が消えます。
- どう変えるか: 役員は、持っている物を整理せずにそのまま送ります。AI が読み、既にある内容に繋げ、案を起こします。役員が直して配ると、配った内容が版になり、紙と区のページと公式 LINE が同じ版から出ます。答えは一か所で数えます。普段の仕事の結果がそのまま次の役員への記録になります。

減るのは事務の層だけです。印刷、配達、設営、当日の運営、人との付き合い、本来の判断は減りません。効果はまだ測っていません。

## 試用手順

作りながら書きます（公開の URL、デモの役員の入り方、架空資料での操作の順、ローカルの起動）。

## Claude の使い方

- 運営支援システムの中: 写真と PDF の読み取りは Workers から Messages API への一回の呼び出し（claude-sonnet-5-5）です。読み取りを既にある内容に繋げる仕事は、入力一つごとに開く Managed Agents のセッション（claude-sonnet-5-5）が、Workers に開けた MCP の五つの手で行います。どのプロジェクトの物かを当てる仕事は claude-haiku-5-5 です。AI が働くのは役員の準備の中だけで、配った後は AI 無しで動きます。住民は AI と話しません。
- 開発: Claude Code を中心に、Opus のセッションが PM を、Sonnet のセッションが作る手を、別の AI が確かめる手を担います。進め方は [docs/STATE.md](docs/STATE.md) と [CLAUDE.md](CLAUDE.md) にあります。
