# fixtures: 架空データ

秋の収穫祭を、段 0 から段 6 まで通すための架空のデータです。**全て架空です。** 実在の自治会、人、事業所、自治体、資料を元にしていません。写真に見える画像も、プログラムで作った合成で、実際に撮った写真でも、実際の手書きでもありません。通し方は [docs/RUNBOOK.md](../docs/RUNBOOK.md) にあります。

去年は 2025 年 10 月 25 日（土）、今年は 2026 年 10 月 24 日（土）の祭りで、雨で会場が変わる前日は 10 月 23 日（金）です。

## 架空であることの印

- 人と事業所の名前には、頭に「架空 」を付けています（例: 架空 木村、架空 商店A）。名前を実在の誰かに見せかけないためと、`grep` で見つけるためです。
- 電話は `000-0000-xxxx`、メールは `festival@example.invalid` です。実在しない形です。
- 自治体は「架空市」、自治会は「架空の区」です。公民館、広場、ホール、集会室は一般の名前で、実在の施設を指しません。
- Word、Excel、PDF、文、市の通知の画像には、資料の中にも「全て架空」と書いています。名簿の CSV、LINE の webhook の JSON、紙の写真風の画像は、形を壊さないため、名前の印だけにしています（この README と RUNBOOK で明記します）。

## 作り方

全てのファイルは `build/` のスクリプトで作っています。

```bash
python -m pip install -r fixtures/build/requirements.txt
python fixtures/build/build_fixtures.py
```

- `build/build_fixtures.py` が全ての中身を持っています（名簿、文、表、画像の中身）。`build/paper.py` が紙の写真風と手書き風の部品です。
- 手書き風の文字は、教科書体の字体で一字ずつ大きさと傾きと位置をずらして書き、線と丸は揺らして引いています。紙の写真風は、机の上に斜めに置いて台形に歪め、影と明るさのむらと粒を足した物です。
- 乱数の種は固定してあり、画像、PDF、文は作り直しても同じ物ができます（Word と Excel は中身が同じで、ファイルの日時だけ変わります）。
- 字体は Windows に入っている BIZ UD ゴシック、BIZ UD 明朝、UD デジタル教科書体を使います。字体のファイルはこのリポジトリに置いていません。他の環境では、環境変数 `FIXTURE_FONT_DIR` で同じ名前の字体のある場所を指します。
- 実在の資料は読み込みません。内容は全て、この作業のために書いた物です。

## 権利と再利用の条件

- 内容、図、文、画像は、このリポジトリのために作った自作の物です。実在の資料の複製や断片は入っていません。
- このリポジトリの [LICENSE](../LICENSE)（Apache License 2.0）に従います。
- 再利用する時のお願いです（ライセンスに条件を足す物ではなく、誤解を避けるための注意です）。
  - 「架空」の印を消さず、架空のデータとして使ってください。
  - 実在の人、団体、自治体の資料として示さないでください。写真風の画像を、実際に撮った写真として示さないでください。
  - 手書き風の画像を、手書きの認識の精度の証拠として使わないでください。
- 画像に使った字体のうち、BIZ UD ゴシックと BIZ UD 明朝は SIL Open Font License です。UD デジタル教科書体は Windows に同梱の字体で、手書き風の文字の画像にだけ使っています。字体そのものは再配布していません。

## 確かめていない物

- 本物の手書き、本物のスマホの写真での読み取りは確かめていません。合成の画像は読みやすい方に寄っています。実運用の精度とは別に考えます（報告に、本物の手書きが要る枚数を書いています）。
- Word は、ファイルの構造を作っただけで、Word 本体での見え方は確かめていません。
- これらを製品に入れて読ませた結果は、まだありません。通した結果は `docs/EVIDENCE/` に確かめる手が書きます。
