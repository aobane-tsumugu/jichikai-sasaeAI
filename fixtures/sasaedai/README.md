# ささえ台自治会のデモ資料（25点）

ささえ台自治会に、新しい役員になったつもりで送る資料です。審査員の方が試すときは、[審査員の案内](https://jichikai-guide.aobane-tsumugu.com/)だけを使ってください。このフォルダの資料は、ささえ台自治会にもう送ってあります。ハッカソンの期間中に、この中の`_make`のスクリプトで作りました。自治会、人、店、学校、町の名前は、どれも実在しません。

関係する資料15点（`01_関係する資料`）と、関係のない資料10点（`02_関係ない資料`）を混ぜて送ります。関係する資料は、10月に済んだ秋の収穫祭の物13点と、これからの12月の年末の見回りの去年の物2点です。手元の資料を分けずにそのまま送る、という使い方を試すためです。関係のない資料は、どの準備にも入らずに残るのが期待する動きです。

中身が少しだけ違う二つの資料の組を三つ入れてあります。ファイル名からはどちらが新しいか分からないようにしてあります。組1と組2は、どちらが新しいか分からないまま、二つを一緒に選んで同じ回に送ります（手元にあった物をとりあえず全部送る、よくある送り方）。組3は、片方を先に送り、もう片方をあとから出てきた物として送ります。

## 年末の見回り（これからの行事）

22と23は、年間の予定の写真にある「12月 年末の見回り」の去年（2025年度）の資料です。秋の収穫祭は10月に済んだ行事のまま、年末の見回りはこれからの行事として、秋とは別に入れてあります。お知らせには去年の日時（2025年12月26日から28日の夜8時、集会所の前に集合）、持ち物、申し込みの締切と問い合わせ先が、当番表には日ごとに回る班と世帯があります。今年の日付は書いていません。今年の日は役員が決めます。

## 三つの組の答え

資料の中には書いていません。製品の動きを確かめるために使います。

### 組1 去年の案内

- `2025年度_秋の収穫祭のご案内.docx`と`2025年度_秋の収穫祭のご案内(1).docx`
- 違いは二か所です。返事の締切（無印は10月5日（日）、(1)は10月3日（金））と、抽選会の有無（無印はあり、(1)はなし）。
- 中身に日付は書いていません。新しさはWordの中の`docProps/core.xml`の作成日と更新日で持ちます。無印は2025年9月20日、(1)は2025年9月12日です。
- 答え: 無印の方が新しい版です。

### 組2 去年の当番表

- `2025年度_秋の収穫祭の当番表.xlsx`と`2025年度_秋の収穫祭の当番表 - コピー.xlsx`
- 違いは、豚汁と片付けの世帯を二つ入れ替えたことだけです。元の方は豚汁が鈴木、渡辺、小林（2班）、片付けが山本、中村（5班）。コピーの方は小林（2班）と中村（5班）が入れ替わっています。
- 新しさはExcelの中の作成日と更新日で持ちます。元の方は2025年10月1日、コピーの方は2025年10月10日です。
- 答え: コピーの方が新しい版です。

### 組3 今年の役員会のメモ

- `2026年4月_役員会のメモ.jpg`と`2026年4月_役員会のメモ_2.jpg`
- 違いは秋の収穫祭の日だけです。無印は10月18日（日）、_2は10月25日（日）。
- 新しさは写真の撮影日（EXIFのDateTimeOriginal）で持ちます。無印は2026年4月12日、_2は2026年4月19日です。
- 答え: _2の方が新しい版です。今年の資料なので、製品は役員に「どちらにしますか」と、違う所と日付を添えて聞く場面になります。

ファイルの更新日時も中身の日付に揃えてありますが、コピーや送信で変わることがあるので、答えの根拠にはしていません。

## 作り直す

`_make`のスクリプトで作り直せます（Windowsの字体を使います）。作り直したあと、開き直して中身を確かめるところまで行います。

~~~sh
cd _make
python -X utf8 make_all.py
~~~

写真風の画像はプログラムで描いた合成で、本物の写真や手書きではありません。この資料で確かめた結果を、本物の写真や手書きの読み取りの精度として扱わないでください。

## 審査員が送って試す資料（03_審査員が送る資料）

審査員の方は、このフォルダを開く必要はありません。同じ 4 点を、[審査員の案内](https://jichikai-guide.aobane-tsumugu.com/)から落とせます。

このフォルダは、手元でSasaeAIを動かして試す人のための、同じ資料の写しです。25 点を送ったあとの自治会に送って、読み取りを試すための 4 点です。25 点と同じ物を送ると、二度は入れないので、別に作りました。

| 資料 | 関係するか | 送ったあとの期待する動き |
|---|---|---|
| 2025年度_年末の見回りの記録.docx | 関係する（年末の見回り） | 「年末の見回りの資料のようです」と出て、準備中の年末の見回りに入れられる |
| 2025年度_新年の集まりのご案内.docx | 関係する（新しい行事） | 新年の集まりの資料として分かれ、新しく準備を始められる |
| 2025年度_春の清掃の班割り.xlsx | 関係する（新しい行事） | 春の清掃の資料として分かれる |
| 宅配ピザのちらし.jpg | 関係ない | どの準備にも入らずに残る |

作り方は `_make/make_judge.py` です。`python -X utf8 _make/make_all.py` で、25 点と一緒に作り直して確かめます。
